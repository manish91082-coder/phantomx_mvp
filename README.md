# PHANTOMX MVP

**Flash Loan Ghost Hunter | Clean Bootstrap | Mission-Controlled DeFi Arbitrage MVP**

## Mission
Build a zero-mandatory-cost, serverless-first, evidence-driven DeFi arbitrage system that can discover real opportunities, deterministically verify economic and execution truth, execute atomically only when every hard gate is GREEN, and prove realized positive net PnL from on-chain receipt plus independent wallet reconciliation.

## Safety boundary
Live capital is BLOCKED during bootstrap and remains BLOCKED until every required safety/economic gate is independently proven. No private keys, seeds, credentials, or secrets belong in this repository.

## MVP boundary
1. One chain at a time.
2. Direct two-pool spatial arbitrage first.
3. Real on-chain quotes and pool state.
4. Exact fee/gas/slippage/price-impact accounting.
5. Provider authenticity and exact repayment verification.
6. Deterministic authorization before execution.
7. Receipt and wallet reconciliation before a realized-profit claim.
8. V3 triangular/multi-hop engine is an expansion track after V2 safety gates are GREEN.

## Core principle
**AI proposes. Deterministic verification decides. Executor executes. Evidence proves.**

## Project continuity
Canonical state is kept in `control/`. Every material milestone must produce a reproducible evidence artifact and update the state checkpoint.
